# DoomBap
80s Marvel Supervillain × Gritty Boom-Bap Instrument Plugin

## Build
1. Install JUCE 7 or 8
2. Edit CMakeLists.txt → set your JUCE path
3. mkdir build && cd build
4. cmake .. -G "Xcode"   (or "Visual Studio 17 2022" / Ninja)
5. cmake --build . --config Release

## Features
- Dual oscillators + sub + noise
- Heavy distortion + saturated filter
- 16-step sequencer with swing
- 40+ supervillain + boom-bap presets
- Neon comic UI
